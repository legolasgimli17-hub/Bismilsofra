# GitHub aktarımı

Bismil Sofra v0.9 kaynak kodları özel `legolasgimli17-hub/Bismilsofra` deposuna aktarılmıştır. GitHub Actions bağımlılık kurulumundan sonra test, typecheck ve web build koşularını çalıştırır.

**Önemli:** GitHub'a aktarım canlı dağıtım değildir. Gerçek sipariş pilotu için gerçek PostgreSQL, OIDC kimlik doğrulama, durum senkronizasyonu, bildirim güvenliği, KVKK uyumu ve sipariş uçtan uca testleri gereklidir.
